## Required before an open-source or mobile release
1. Identify the exact soundtrack and source URL; check metadata, download history or licensing receipts if available.
2. Record creator, license terms, date/version, and any required credit.
3. Check whether the original music file may be hosted publicly as a standalone downloadable repository asset; permission to use it *in a game* is not necessarily permission to sublicense it or distribute it separately.
4. Establish provenance and terms for fonts and art.
5. Select a code license separately from asset licenses and clearly mark exclusions.

**Do not claim the MP3 is Pixabay-licensed based on its filename or an unconfirmed recollection. Do not apply MIT or any other code license to all bundled assets by default.**
